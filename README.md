## Remediation Roadmap

- **Critical (9.0-10.0):** Fix immediately (0-24 hours)
- **High (7.0-8.9):** Fix within 1-7 days
- **Medium (4.0-6.9):** Fix within 1-30 days
- **Low (0.1-3.9):** Document and monitor
